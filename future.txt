## Code Quality & Implementation Style

- Write clean, professional, production-quality code.
- Code should read naturally and follow normal developer conventions.
- Use meaningful variable, function, component, and file names.
- Avoid unnecessary comments, artificial explanations, or repetitive code.
- Do not over-engineer simple features.
- Keep components modular and reusable.
- Keep data, UI, logic, and utilities properly separated.
- Avoid duplicated code and unnecessary abstractions.
- Follow consistent formatting and TypeScript conventions.
- Use realistic implementation patterns suitable for a real production project.
- Do not generate placeholder logic where a proper implementation is reasonably possible.
- Use clear error handling and sensible loading states.
- Keep the implementation maintainable so another developer can understand and continue the project easily.
- When providing code, provide complete, directly usable files that can be pasted into VS Code.
